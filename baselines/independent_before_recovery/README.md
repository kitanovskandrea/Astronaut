# Pre-recovery independent policies

These15frozenselectedcheckpoints are the delivered November7independent policies, using the same official0db0652coursephysics/rewards as the recovery. They are retained for controlled comparison on the new holdout. The original manifest preserves their configurations/hashes; its old checkpoint-history paths refer to the full archived project, not additional models in this baseline folder.

The primary curriculum now inherits learned flight/avoidance values; these baseline policies started from zero separately. Run python -m astronaut_rl.compare_recovery from the project root to reproduce their physical-game comparison against the new selected policies. No earlier custom-reward or different-physics policy is mixed into this comparison.
