# Validation record

Revised 2026-11-10. Python 3.12.14, arm64; unchanged official famnit-gym commit `0db0652ad3b8cece05d476c56637a3dcb56557cd`. Default physics and rewards are retained.

- All 70 unit/integration tests pass, including Bellman arithmetic, public-feature encoding, exact parent-Q transfer, zero inherited visit counts, macro-frame reward/discount handling, termination/truncation, gate selection, isolated evaluation, deterministic serialization and corrupted-record rejection.
- All five independent chains qualified in flight, asteroid avoidance and oxygen collection. Each starts flight from zero, learns avoidance from its own selected flight policy, and learns collection from its own selected avoidance policy. No scripted action controller or reward shaping is used.
- Full verification replayed 11,315 evaluation episodes, checked 240 validation checkpoints and all 15 selected stage models. Per-episode outcomes, summaries, model hashes, visit counts, initialized rows, gate/stability decisions, exact checkpoint selection and cumulative costs match the recorded artifacts.
- Eight configurations repeated in earlier sequential runs produced byte-identical selected and final-budget model files in the parallel run. Exact hashes are in `results/reproducibility.json`. Evaluation preserves Q values, visits and the learner RNG.
- The actual browser stream measured about 60 physics frames per second. Scene/headless outcomes, action cadence, sprites, task switching, replay restart, isolated fresh training and server shutdown pass integration checks. Native Close/Escape exits are tested with an offscreen driver.
- The final batch used five parallel processes, with stages sequential inside each chain. Reported stage seconds are active per-process wall time under concurrent load. They exclude initialization, validation, tests, exports, rendering and progress IO. Cumulative costs include prerequisite learning; this is not an equal-budget from-zero timing comparison.
- On separate final scenarios, five-policy mean full survival is 100% flight, 98.6% avoidance and 96.8% collection; oxygen averages 5.32 tanks. Wrapped stages use 100 episodes per policy; flight has one deterministic scenario. These finite measurements do not guarantee every future episode.
- Paired frozen-policy evaluation uses identical official physics, default rewards and final episode seeds for the retained pre-recovery and recovered models. Avoidance completion improves from 30.6% to 98.6%; oxygen completion from 6.4% to 96.8%, and tanks from 2.17 to 5.32. Raw paired data and sample SD across policies are under `results/recovery_comparison/`.
- The generated report, seven SVG figures and A1 landscape poster use the measured records. The final PDF has been rendered and visually checked. Oxygen TD residuals do not converge to zero in this run; improved behavior and low loss are separate findings.
- The Desktop virtual environment has the correct source snapshot and `pip check` reports no broken requirements. The packaged program contains portable relative model paths, the official wheel/license/provenance and all checkpoint data. `.venv` and personal `runs/` are excluded from the ZIP.

Reproduce with `python -m astronaut_rl.batch --out rerun_results --models rerun_models --work rerun_jobs --workers 5`; verify using `python -m astronaut_rl.verify --results rerun_results --models rerun_models`. The sequential `astronaut_rl.experiment --variant all` uses the same learned policies with different timings. `--skip-checkpoints` is a shorter final-test-only verification. Hardware load changes timings.
